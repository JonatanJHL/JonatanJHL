## 💼 Experiencia profesional

### Desarrollador de Software — SERVNET *(2021 – 2025 · 4+ años)*
> ISP con cobertura en CDMX. Ingresé como becario de automatización y escalé a desarrollador, participando en el diseño e implementación de múltiples sistemas internos de producción.

**🔷 CAPA 8 — Sistema de Gestión de Colaboradores**
Plataforma web completa que reemplazó hojas de cálculo dispersas con una solución digital centralizada para Recursos Humanos.
- Autenticación segura con Google OAuth 2.0
- Control de acceso basado en roles (RBAC): Colaborador / Líder / RRHH / Admin
- Módulo de vacaciones con flujo de aprobación, organigrama interactivo y panel de KPIs
- Gestión de activos tecnológicos asignados por colaborador
- `PHP · MySQL · HTML5 · Bootstrap · JavaScript · Google OAuth 2.0`

**🔷 Integración WSAS ↔ Slack (Omnicanalidad)**
Sistema de notificaciones en tiempo real conectando el helpdesk con Slack para reducir tiempos de respuesta ante incidencias críticas.
- Clasificación automática de tickets por criticidad (Crítico / Alto / Medio)
- Flujo bidireccional: respuestas desde Slack se sincronizan al ticket
- Generación automática de sala Google Meet para incidentes críticos
- Segmentación de clientes prioritarios (Critical Care, Élite, Premium)
- `PHP · WHMCS Hooks · Slack API · Webhooks · MySQL`

**🔷 Módulo CFDI 4.0 — Actualización de datos fiscales**
Herramienta de autoservicio para actualización de datos fiscales bajo normativa SAT, sin intervención manual del personal.
- Autenticación por token único (URL personalizada por cliente)
- Lectura automática de Constancias de Situación Fiscal vía PDF.js + RegEx
- Flujo de validación administrativa antes de aplicar cambios al sistema principal
- `PHP · MySQL · JavaScript · PDF.js · PHPMailer · Bootstrap`

**🔷 Dashboard de Facturación y Cartera Vencida**
Reportes consolidados de adeudos con filtros dinámicos y exportación a Excel.
- Cálculo automático de adeudos netos en MXN y USD (pagos parciales + notas de crédito)
- Clasificación por antigüedad: 0–30 / 31–60 / 61–90 / 91–120 / 121+ días
- `PHP · MySQL · WHMCS · Chart.js`

**🔷 Automatización de Cronjobs en servidor**
Scripts periódicos vía SSH: alertas de facturas con adeudo, recordatorios de actividades pendientes y reportes programados automáticos.
