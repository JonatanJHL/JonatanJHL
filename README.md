## 💼 Experiencia profesional

### Desarrollador — SERVNET *(2022 – 2025)*

Ingresé como becario de automatización y crecí hasta rol de desarrollador, participando en el diseño e implementación de múltiples sistemas internos:

**🔷 CAPA 8 — Sistema de Gestión de Colaboradores**
Plataforma web completa para la administración de recursos humanos. Reemplazó hojas de cálculo dispersas con una solución digital centralizada.
- Autenticación segura con Google OAuth 2.0
- Módulo de solicitudes de vacaciones con flujo de aprobación
- Control de acceso basado en roles (RBAC): Colaborador / Líder / RRHH / Admin
- Organigrama interactivo, directorio institucional y panel de KPIs
- Gestión de activos tecnológicos asignados por colaborador
- Stack: PHP · MySQL · HTML5 · Bootstrap · JavaScript

**🔷 Integración WSAS ↔ Slack (Omnicanalidad)**
Sistema de notificaciones en tiempo real que conectó el sistema de tickets con Slack para reducir tiempos de respuesta ante incidencias críticas.
- Clasificación automática de tickets por criticidad (Crítico / Alto / Medio)
- Flujo bidireccional: respuestas desde Slack se sincronizan al ticket
- Generación automática de sala Google Meet para incidentes críticos
- Segmentación de clientes prioritarios (Critical Care, Élite, Premium)
- Stack: PHP · WHMCS Hooks · Slack API · Webhooks · MySQL

**🔷 Módulo CFDI 4.0 — Actualización de datos fiscales**
Herramienta de autoservicio para que clientes actualizaran sus datos fiscales cumpliendo la normativa SAT sin intervención manual del personal.
- Autenticación por token único (URL personalizada por cliente)
- Lectura automática de Constancias de Situación Fiscal (PDF.js + RegEx)
- Flujo de validación administrativa antes de aplicar cambios al sistema principal
- Stack: PHP · MySQL · JavaScript · PDF.js · PHPMailer · Bootstrap

**🔷 Módulo de Facturación con Adeudo**
Dashboard de cartera vencida con reportes consolidados, filtros dinámicos y exportación a Excel.
- Cálculo automático de adeudos netos (MXN y USD) considerando pagos parciales y notas de crédito
- Clasificación de adeudos por antigüedad: 0–30, 31–60, 61–90, 91–120, 121+ días
- Stack: PHP · MySQL · WHMCS

**🔷 Automatización de Cronjobs en servidor**
Scripts de automatización ejecutados periódicamente vía SSH: alertas de facturas con adeudo, recordatorios de actividades pendientes y reportes programados.
